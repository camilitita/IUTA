Características Generales Soporte Compatibilidad B.D Registros
En su diseño presenta una interfaz de usuario moderna y adaptable, intuitiva y fácil de usar en diversos dispositivos. Su diseño modular permite a las empresas implementar solo las aplicaciones y funcionalidades que necesitan.
Está desarrollado utilizando una combinación de lenguajes de programación, incluyendo C#, JavaScript y SQL.
Dynamics 365 es principalmente una solución basada en la nube, lo que permite el acceso desde cualquier lugar con conexión a Internet. También ofrece opciones de implementación local (on-premises) e híbridas para empresas con requisitos específicos.		 Microsoft ofrece diversos niveles de soporte para Dynamics 365, que varían según el plan de suscripción.
El soporte incluye asistencia técnica, actualizaciones de software, correcciones de errores y acceso a recursos en línea.
Además, existe una amplia red de partners de Microsoft que brindan servicios de implementación, personalización y soporte.		 Dynamics 365 se integra de forma nativa con otros productos de Microsoft, como Microsoft 365 (Office 365), Power BI y Azure.
También ofrece compatibilidad con diversas aplicaciones y servicios de terceros a través de API y conectores.		 Utiliza Microsoft Dataverse como su base de datos principal. Es una plataforma de datos segura y escalable que permite almacenar y administrar datos de forma eficiente y que utiliza Azure SQL. Permite crear y administrar una amplia variedad de registros, incluyendo Clientes, Contactos, Productos, Pedidos, Facturas y Actividades.
La cantidad de registros que se pueden crear depende del plan de suscripción y la capacidad de almacenamiento disponible.
Reportes Seguridad Comportamiento Observaciones
Dynamics 365 ofrece una amplia gama de capacidades de informes y análisis, incluyendo: Reportes predefinidos para diversas áreas de negocio (Operacionales, Analíticos, Paneles de Control). Reportes personalizados. Integración con Power BI para análisis avanzados y visualización de datos. La cantidad de reportes es muy amplia, y depende de las aplicaciones de Dynamics 365 que se estén utilizando. Implementa rigurosas medidas de seguridad para proteger los datos y el acceso al sistema, incluyendo: Autenticación de usuarios y control de acceso basado en roles.
Cifrado de datos en tránsito y en reposo. Auditoría de actividades y registros de acceso.
Protección contra amenazas cibernéticas. Microsoft Azure, donde reside la información, posee altos estándares de seguridad.		 Entrada: Permite la entrada de datos a través de diversos canales, incluyendo formularios web, importación de archivos y API. También se integra con otras aplicaciones y servicios para la captura automática de datos.
Salida: Dynamics 365 permite la generación de reportes, paneles y exportación de datos en diversos formatos (Excel, PDF, etc.). También se integra con otras aplicaciones y servicios para la distribución y el intercambio de datos.		 La amplia gama de funcionalidades y opciones de personalización puede hacer que sea complejo de implementar y utilizar, especialmente para usuarios nuevos.
La implementación y el mantenimiento de este sistema pueden ser costosos, especialmente para pequeñas y medianas empresas.
Al ser una solución basada en la nube, Dynamics 365 depende enormemente de una conexión a Internet estable.
La generación de informes puede llegar a ser limitada, y la personalización de los mismos, puede ser compleja.
